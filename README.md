# my-project

## Description

브라우저에서 바로 사용할 수 있는 간단한 할 일 목록(To-Do List) 웹페이지입니다.
할 일 추가/완료 체크/삭제 기능을 제공하며, 입력한 내용은 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## Installation

별도의 설치나 서버가 필요 없습니다. 저장소를 클론한 뒤 `index.html` 파일만 있으면 됩니다.

```bash
git clone https://github.com/dreamer0191-eng/my-project.git
```

## Usage

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

- 입력창에 할 일을 적고 **추가** 버튼(또는 Enter)을 눌러 항목을 추가합니다.
- 체크박스를 클릭해 완료 여부를 표시합니다.
- 항목 오른쪽의 **×** 버튼으로 삭제합니다.
- **완료된 항목 지우기** 버튼으로 완료된 항목을 한 번에 삭제할 수 있습니다.
